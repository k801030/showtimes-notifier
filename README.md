## 本地測試與執行 (使用 Makefile)
我們準備了快捷指令，讓您可以非常方便地在本地操作：

1. **安裝套件**：
   ```bash
   make install
   ```
2. **設定通知（二選一）**：
   - 打開 `.env` 檔案，填入您的 Discord Webhook URL 或 Telegram Token。
3. **強制發送測試通知**：
   ```bash
   make test
   ```
4. **執行標準檢查**：
   ```bash
   make run
   ```
5. **清除本地快取與狀態 (重置通知閥值)**：
   ```bash
   make clean
   ```

## 雲端部署 (GCP)

### 1. 首次初始化 (僅需執行一次)
如果是第一次部署到這個 GCP 專案，請先執行以下指令來啟用必要的 API、建立 Firestore 與設定 IAM 權限（此步驟會耗時約 2~3 分鐘等待同步）：
```bash
make setup
```

### 2. 快速部署 (每次更新程式碼或設定時執行)
當您修改了程式碼、排程、影城 ID 或通知管道，且想同步到雲端時，只需要執行：
```bash
make deploy
```
系統會直接進行 Cloud Functions 與 Scheduler 的更新，每次部署只需十幾秒到一分鐘即可完成！
